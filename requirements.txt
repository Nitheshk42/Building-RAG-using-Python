# Pinned: langchain-core -> langsmith pulls zstandard, and the resolver was landing on

# Embeddings
# NOTE: sentence-transformers / langchain-huggingface (and the torch + transformers +
# onnxruntime they pull in, ~800MB) were removed on purpose. Embeddings now call Hugging
# Face's hosted Inference API instead (see src/embeddings.py) via
# langchain_community.embeddings.HuggingFaceInferenceAPIEmbeddings, which only needs plain
# `requests` (already a transitive dep) - no local model weights, no torch.

# Vector Store
# We used to pin chromadb==0.4.24 to dodge a Rust-binding bug that only hit Python 3.14
# (Streamlit Cloud's runtime at the time). Since local dev, the Docker image, and Cloud Run
# all now standardize on Python 3.11, that specific reason no longer applies - and 0.4.24
# turned out to have ITS OWN separate tenant-bootstrap bug (chromadb.Client() ->
# _validate_tenant_database failing with "Could not connect to tenant default_tenant" even
# on a clean, correctly-versioned setup). langchain_community's Chroma wrapper uses that
# old, deprecated chromadb.Client() global-singleton factory internally - the fix is moving
# to the dedicated langchain-chroma package below, which uses chromadb.PersistentClient()
# directly (the modern, non-deprecated, per-directory client) and never hits that code path.
langchain-chroma==0.2.6
chromadb>=1.0.20,<2.0.0
# Linux-only (no macOS wheels exist) - not needed locally, app.py already skips it
# gracefully via try/except if it's missing.
pysqlite3-binary; sys_platform == "linux"
